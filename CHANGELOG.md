# Changelog

## 1.0.10

- Fixed the game crashing on startup with Essential 1.5.1.
- Fixed the shader glint fix not working with Essential 1.5.1.
- "Disable Telemetry" now also blocks the telemetry Essential sends when you share a world.
- Fabric: Fabric API is now listed as required. On 1.19.2 the game crashed on startup without it.
- Now requires Essential 1.5.1 or newer (1.4.1.1 on 1.21.2, 1.21.3, 1.21.5–1.21.7 and 1.21.9, where Essential no longer updates). With an older Essential, the game tells you to update it instead of starting.
